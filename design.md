# 🚀 Mini Decision Support System (DSS) - Design System

## 🎯 Loyiha Maqsadi
Ushbu tizim Nuxt.js (v4) yordamida ma'lumotlarga asoslangan qaror qabul qilishni avtomatlashtirish uchun mo'ljallangan. 

## 🤖 Claude Code & Agentic Rules (GitHub Trending Best Practices)
*   **Plan Mode First:** Har qanday murakkab vazifani bajarishdan oldin implementation plan (amalga oshirish rejasi) tuzing.
*   **Surgical Edits:** Faqat kerakli kod qismlarini o'zgartiring, yon atrofdagi kodlarga yoki formatlashga tegmang.
*   **Verify Relentlessly:** Har bir o'zgarishdan so'ng testlarni ishga tushiring va xatolarni IDE orqali tekshiring.
*   **Simplicity First:** Agar 200 qatorli kodni 50 qatorda yozish imkoni bo'lsa, har doim qisqa va sodda yo'lni tanlang.
*   **No Laziness:** Muammoning vaqtinchalik yechimini emas, balki tub ildizini topib tuzating.

## 🎨 Nuxt.js Design Patterns (Modern UI/UX)
*   **Nuxt Content (Git-based CMS):** Tizim tushuntirishlari va yordamchi ma'lumotlarni Markdown fayllarda saqlash.
*   **Nuxt UI v4 Template:** Dashboard va statistik diagrammalar uchun rasmiy `nuxt-ui-templates/docs` andozasidan foydalanish.
*   **Modular Architecture:** Komponentlarni `design-system` sifatida alohida plugin yoki modul ko'rinishida saqlash.

## 🛠 Texnik Stack
- **Framework:** Nuxt.js 4 (Stable)
- **Styling:** Tailwind CSS + Nuxt UI
- **Data Fetching:** Nuxt Content + SQLite integration
- **State:** Pinia / Zustand (minimalistic)

## 🏗 Ma'lumotlar Oqimi
1. Foydalanuvchi ma'lumotlarni kiritadi.
2. Tizim mantiqiy qatlami (Logic layer) statistik modellarni qo'llaydi.
3. Natija vizual diagramma (Nuxt Charts) ko'rinishida taqdim etiladi.

## 📝 GitHub Workflow Commands
- `npm run dev` — Mahalliy serverni ishga tushirish.
- `npm run build:system` — Dizayn tizimini generatsiya qilish.
- `npm test` — Qaror qabul qilish modullarini tekshirish.
